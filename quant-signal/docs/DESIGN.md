# 설계 및 사업화 계획

> 제품 한 줄 정의
> **"4개 시장을 하나의 규칙으로 채점해서, 살지 말지가 아니라 *얼마에, 언제, 얼마나* 를 알려주는 앱"**

---

## 1. 아키텍처

```
L1 데이터   US주식 / KR주식 / US선물 / 코인 어댑터 -> 공통 OHLCV 스키마
L2 엔진     레짐 판정 -> 팩터 스코어링 -> 진입가·손절가·비중  (결정론적, 백테스트 가능)
L3 AI       뉴스·공시 -> 이벤트 리스크 점수 / 스코어 -> 한국어 설명문
            ※ 매매 결정 자체는 LLM 에 맡기지 않는다
알림        푸시 / 텔레그램 / 알림톡
```

### 규칙 엔진과 AI 의 경계

| | 규칙 엔진 (L2) | AI (L3) |
|---|---|---|
| 역할 | 점수·가격·비중 **계산** | 근거 **설명**, 텍스트 해석 |
| 재현성 | 100% | 매번 다름 |
| 백테스트 | 가능 | 불가능 |

LLM 이 "지금 사세요"를 직접 판단하면 백테스트가 불가능해지고, 그 순간
유료화 근거가 사라진다. 성과를 숫자로 증명하지 못하는 시그널 서비스는
결국 리딩방과 구분되지 않는다.

## 2. 시장별 신호 설계

### 미국 주식 (P0 구현 완료)
- 유니버스: S&P 500 + 나스닥 100
- 팩터: 모멘텀(12-1) / 추세(200일선 이격) / 저변동성 / 거래량 확인
- P1 추가 예정: 퀄리티(GPA, ROIC), 밸류(EV/EBIT) — 유료 재무데이터 필요
- 레짐 필터: SPY 200일선, VIX 기간구조, HYG/IEF 신용 스프레드

### 국내 주식
- 유니버스: KOSPI 200 + KOSDAQ 150
- 미국 팩터를 그대로 쓰면 안 된다. 한국 고유 변수 추가:
  - 외국인·기관 순매수 누적 (5/20일)
  - 공매도 잔고 비율 변화
  - 지주사·거래정지·관리종목 하드 필터
- 환율 레짐: USD/KRW 20일 추세 -> 국내주식 전체 비중 스케일에 반영

### 미국 선물 (NQ, ES, GC, CL)
- 자산 4개로는 횡단면 랭킹이 무의미 -> **추세추종**이 정답
- TSMOM: 1·3·6·12개월 수익률 부호 합성
- 변동성 타겟팅: `비중 = 목표변동성(연 15%) / 실현변동성(60일)`
- 롤 수익률: 근월/차월 스프레드로 콘탱고·백워데이션 판정 (원유에서 특히 중요)
- 초보자용은 ETF 매핑(QQQ/SPY/GLD/USO), 선물 계약은 상급 플랜

### 비트코인
- 사이클: MVRV-Z, 200주 이동평균 대비 위치, 실현가격
- 온체인 수급: 거래소 순유입, 장기보유자 공급 변화
- 파생 과열: 펀딩비 누적, 미결제약정 급증
- 24/7 이라 알림 폭주 위험이 가장 크다 -> 쿨다운 6시간, 야간 무음 필수

## 3. 실시간 신호 (P0.5)

### 지연 등급

| 수준 | 판단 |
|---|---|
| 틱 단위 (<1초) | 불필요. HFT 영역이고 개인 대상 구독으로 이길 수 없다 |
| **봉 마감 기준 (1m/5m/15m)** | **정답.** 체감 지연 최대 5분 |
| 일봉 마감 | 팩터·레짐 (P0 가 여기) |

### 봉 마감 후에만 발송 — 리페인팅 방지

진행 중인 봉의 값으로 알림을 보내면, 봉이 닫힐 때 조건이 사라져
"알림은 갔는데 차트엔 신호가 없는" 상황이 생긴다. 백테스트 성과와
실거래 성과가 갈리는 1순위 원인이다.

- 발송은 **봉 확정 시점에만**
- 예외는 **손절선 이탈 하나뿐** (즉시 발송)

### 거짓 신호 억제 장치

**① 멀티 타임프레임 확인** — 5분봉 신호 발생 시 1시간봉 추세와
일봉 레짐이 모두 같은 방향일 때만 발송. 거짓 신호가 절반 이하로 준다.

**② 상태 머신** — 조건이 참인 동안 반복 발송 금지.
`대기 -> [충족] -> 발송 -> 무장해제 -> [이탈] -> 대기`

### 쓸 수 있는 차트 신호 / 없는 신호

| ✅ 객관적 계산 가능 | ❌ 배제 |
|---|---|
| 이동평균 교차 + 거래량 확인 | 헤드앤숄더 |
| 박스권 돌파 (ATR 대비 돌파폭) | 엘리엇 파동 |
| RSI 다이버전스 | 추세선 수동 작도 |
| 볼린저 스퀴즈 | 차트 이미지 AI 판독 |
| 지지선 도달 / 손절선 이탈 | |

오른쪽 항목은 사람마다 다르게 그린다. 재현성이 없으면 백테스트가
불가능하고, 백테스트가 없으면 구독료를 받을 근거가 없다.

### 알림 채널 도달 속도

| 채널 | 도달 | 비고 |
|---|---|---|
| 텔레그램 봇 | 1~2초 | 가장 빠르고 확실. 무료. **1순위** |
| Web Push (안드로이드) | 2~5초 | 무료 |
| Web Push (iOS) | 수 초~수 분 | 홈화면 추가 필수, 지연 가능 |
| 카카오 알림톡 | 수 초 | 건당 과금, 유료 플랜용 |

엔진이 빨라도 iOS 푸시가 늦으면 의미가 없다. 실시간을 내세우려면
텔레그램 연동이 필수다.

## 4. 데이터 소스와 비용

무료 데이터로 만든 시그널을 유료로 재배포하면 대부분 약관 위반이다.
이 사업의 가장 흔한 실패 지점.

| 시장 | MVP (검증용) | 유료화 단계 |
|---|---|---|
| 미국 주식 | yfinance | Polygon.io / EODHD / Databento |
| 국내 주식 | pykrx, DART OpenAPI | KRX 정보데이터시스템 유료 라이선스 |
| 미국 선물 | yfinance 연속물 | Databento, CME 라이선스 |
| 비트코인 | 바이낸스·업비트 공개 API | Glassnode 등 온체인 유료 |

- DART 공시는 재무데이터 활용이 자유로운 편 -> 국내 팩터의 뼈대
- 증권사 API(키움·한투·LS)는 무료지만 **재배포 금지**가 일반적
- 코인 거래소 공개 API 가 가장 관대 -> **실시간 유료화는 비트코인부터**

정확한 요금과 약관은 시점에 따라 바뀌므로 유료 전환 직전 직접 확인할 것.

## 5. 구독 설계

| 플랜 | 가격(안) | 내용 |
|---|---|---|
| Free | 0원 | 1개 시장, 일 1회, **24시간 지연**, 알림 없음 |
| Pro | 월 19,900원 | 4개 시장, 실시간 알림, 진입가·손절가·비중 |
| Pro+ | 월 49,900원 | 백테스트 리포트, 커스텀 스크리너, API, 선물 계약 단위 |

- Free 의 제한은 **기능이 아니라 지연**으로. 기능을 막으면 가치를 못 느껴
  전환이 안 되고, 지연을 걸면 가치는 느끼되 실전에 못 쓴다.
- 7일 무료 체험 + 카드 등록. 시그널 서비스는 한 사이클을 겪어야 신뢰가 생긴다.
- **성과 대시보드 공개가 최고의 마케팅.** 모든 신호를 발생 시점에 불변
  기록으로 저장하고 누적 성과를 가감 없이 공개한다.
  (`pipeline.write()` 의 `history/` 가 이 목적이다.)
- 결제: 국내 토스페이먼츠 빌링키, 해외 Stripe/Paddle
- 앱스토어 인앱결제(15~30%)를 피하려면 PWA 유지가 유리

## 6. 규제

- **유사투자자문업**: 불특정 다수에게 **동일 내용**의 투자 정보를 유료 제공.
  자본시장법상 신고 대상이며 대표자·임원 교육 이수 및 결격사유 요건이 있다.
  미신고 유료 운영은 형사처벌 대상.
- **투자자문업(등록제)**: 개별 고객 자산·성향에 맞춘 1:1 조언. 요건이 훨씬 무겁다.

> **설계상 갈림길** — 앱이 사용자 계좌 잔고를 읽어 "당신에게 맞는 종목"을
> 제시하면 투자자문업 영역으로 넘어갈 위험이 있다. 모든 구독자에게 동일한
> 시그널과 동일한 비중을 제공하고, 금액 환산은 사용자가 입력한 값으로
> 클라이언트가 계산하는 구조를 MVP 부터 유지한다.
> (`engine/entry.py` 의 비중 공식에 계좌 잔고가 들어가지 않는 이유다.)

그 밖에:
- 수익률 광고 규제: 기간·기준 명시, 원금손실 가능성 고지
- 가상자산: 자문·정보 제공만 하고 매매를 대행하지 않으면 VASP 신고 대상 아님
- 해외 이용자: 미국 거주자 대상이면 SEC 투자자문사 등록 이슈 -> 초기엔 한국 거주자 한정

위는 방향이며 법률 자문이 아니다. 유료 전환 전 금융 규제 전문 변호사 또는
금융감독원 상담을 거칠 것.

## 8. 리스크 3가지

1. **백테스트 과최적화** — 지표를 늘릴수록 과거는 좋아지고 미래는 나빠진다.
   팩터는 시장당 4개 이하, 최근 3년은 튜닝에 쓰지 말고 검증용으로 남긴다.
2. **데이터 라이선스** — 무료 데이터로 만든 걸 유료로 파는 구조는 언제든 멈춘다.
3. **알림 피로** — 기능 부족보다 알림 과다로 더 많이 해지한다. 상한과 쿨다운을
   나중에 붙이지 말고 처음부터 넣는다.
