# 퀀트 시그널

4개 시장(미국주식 / 국내주식 / 미국선물 / 비트코인)을 하나의 규칙으로 채점해
**살지 말지가 아니라 얼마에·언제·얼마나**를 알려주는 시그널 엔진.

현재 단계: **P0 — 미국 주식, 일 1회 배치**

---

## 무엇이 다른가

대부분의 시그널 서비스는 종목만 알려 준다. 이 엔진은 종목마다 다음을 함께 낸다.

| 출력 | 계산 방식 |
|---|---|
| 3분할 매수가 | 종가 −0.5 / −1.0 ATR, 마지막은 20일선 지지 |
| 손절가 | 가중평균 진입가 − 2 × ATR |
| 계좌 비중 | 감내손실% × 진입가 ÷ 주당위험 (상한 10%) |
| 유효기간 | 5거래일 |

비중 공식에 **계좌 잔고가 들어가지 않는다.** 모든 이용자가 같은 비중을 받고,
서버는 개인 자산을 알 필요가 없다. 규제 측면에서도 중요한 설계다 (아래 참조).

---

## 빠른 시작

```bash
pip install -r requirements-dev.txt

# 오프라인 검증 (합성 데이터 — 네트워크 불필요)
python -m engine.cli --source synthetic --limit 40 --out web/data

# 실제 데이터
python -m engine.cli --source yahoo --out web/data

# 대시보드
cd web && python -m http.server 8000   # http://localhost:8000
```

### 주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--source` | `yahoo` | `yahoo` 또는 `synthetic` |
| `--limit` | `0` | 유니버스 상한 (0=전체) |
| `--top-n` | `25` | 출력할 상위 종목 수 |
| `--risk-pct` | `1.0` | 1회 매매 감내 손실률(%) |
| `--demo-regime` | `risk_on` | 합성 데이터 국면: `risk_on`/`risk_off`/`random` |
| `--offline-universe` | off | S&P500 목록 원격 조회 없이 폴백 사용 |
| `--dry-run` | off | 파일로 쓰지 않고 요약만 |

## 구조

```
engine/
  config.py      모든 파라미터 (백테스트에서 여기만 바꾼다)
  indicators.py  ATR, RSI, SMA/EMA, 실현변동성, 모멘텀 — 순수 함수
  regime.py      시장 레짐 (추세 / 변동성 / 신용 3축)
  factors.py     횡단면 팩터 + z-score 합성 -> 0~100 점수
  entry.py       진입가·손절가·비중          <- 제품의 핵심
  scoring.py     점수 -> 액션 매핑
  pipeline.py    전체 실행 -> signals.json
  cli.py         커맨드라인
  data/
    base.py      공통 OHLCV 스키마 (시장 추가 시 여기만 맞추면 된다)
    us_equity.py yfinance 어댑터
    synthetic.py 오프라인 검증용 생성기
    universe.py  S&P500 목록 + 폴백
web/             PWA 대시보드 (signals.json 만 읽는 정적 페이지)
```

### 레짐 게이트

추세(SPY 200일선) / 변동성(VIX·VIX3M 기간구조) / 신용(HYG·IEF) 3축을 각각 채점한다.

- 3축 전부 양호 → `RISK_ON`
- 과반 양호 → `NEUTRAL`
- 그 외 → `RISK_OFF` → **점수가 100점이어도 신규 진입 신호를 내지 않는다**

판정 근거가 하나도 없으면 보수적으로 `RISK_OFF` 로 떨어진다. 모르면 사지 않는다.

### 팩터 (P0)

| 팩터 | 가중치 | 정의 |
|---|---|---|
| momentum | 0.40 | 12-1개월 수익률 (최근 21일 제외) |
| trend | 0.30 | 200일선 대비 이격도 |
| low_vol | 0.20 | 60일 실현변동성 (역부호) |
| volume_confirm | 0.10 | 5일 / 60일 평균 거래량 비 |

P0 는 **가격·거래량만** 쓴다. 무료 소스로 500종목 재무데이터를 긁으면 결측과
지연 때문에 신호가 오히려 나빠진다. 밸류·퀄리티는 유료 데이터가 들어오는
P1 에서 `factors.FACTORS` 에 등록하고 `config` 가중치만 추가하면 된다.

## 자동 실행

`.github/workflows/signals.yml` 이 미국 장 마감 후(화~토 22:30 UTC) 돌면서
테스트 → 시그널 생성 → `web/data` 커밋을 수행한다. 수동 실행도 가능하다.

> 이 파일은 **저장소 루트의** `.github/workflows/` 에 있어야 동작한다.

## 알아 둘 것

**데이터 라이선스.** yfinance 는 검증용이다. 유료 서비스로 재배포하면 약관
위반 소지가 크다. P3 전에 Polygon / EODHD / Databento 등과 정식 계약이 필요하다.
어댑터가 분리돼 있으므로 `data/us_equity.py` 만 교체하면 된다.

**규제.** 불특정 다수에게 유료로 투자 정보를 제공하면 자본시장법상
유사투자자문업 신고 대상이다. 개별 고객 자산에 맞춘 조언은 투자자문업(등록제)
영역으로 넘어간다. 이 엔진이 계좌 잔고를 받지 않고 모든 이용자에게 동일한
비중을 제시하는 것은 그 경계를 지키기 위한 설계다. 유료화 전 반드시 금융
규제 전문가의 확인을 받을 것.

**과최적화.** 팩터를 늘릴수록 과거 성과는 좋아지고 미래 성과는 나빠진다.
시장당 4개 이하로 제한하고, 최근 3년은 파라미터 튜닝에 쓰지 말 것.

판단과 책임은 투자자 본인에게 있으며 원금 손실이 발생할 수 있다.
